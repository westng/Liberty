# Liberty 宠物 255 级成长生态策略

## 背景

Liberty 的桌面宠物不是传统游戏宠物，而是工作陪伴型成长系统。它的核心价值不是让用户刷数值，而是让用户感觉：自己的真实工作被记录、被回应，并逐步沉淀成一个长期陪伴关系。

当前系统已经具备这些基础能力：

- 工作行为可以给宠物增加成长值。
- 工作行为可以产出 LP。
- LP 可以购买食物、道具、装扮、场景。
- 食物可以提供固定成长值。
- 宠物可以通过气泡台词、动作、成长值动画回应用户。

接下来需要把这些能力统一成完整生态，而不是分散的功能点。

## 设计目标

- 等级上限定为 `255` 级，形成长期成长目标。
- 前期升级要快，让用户每天能感受到反馈。
- 中后期升级逐步变慢，但不能让用户觉得停滞。
- 食物经验值固定，不随宠物等级衰减。
- 等级越高，升级所需成长值越多，因此食物贡献占比自然下降。
- LP 主要来自真实工作行为，食物是成长加速器，不是唯一主线。
- 宠物反馈围绕被照顾、陪伴、恢复精神和一起成长，而不是纯数值播报。

## 核心循环

```text
真实工作行为
→ 获得成长值和 LP
→ 使用 LP 购买食物、道具、装扮、场景
→ 食物提供固定成长值
→ 宠物升级、突破阶段、解锁内容
→ 宠物用动作、台词、动画回应用户
→ 用户形成长期陪伴感
```

## 成长值来源

成长值分为两类：

| 类型 | 来源 | 定位 |
|---|---|---|
| 工作成长值 | 每日打开、创建任务、转写、总结、导出、互动 | 主线成长 |
| 食物成长值 | 用户使用 LP 购买并喂食 | 加速成长和情感反馈 |

工作成长值代表用户真实使用 Liberty。食物成长值代表用户把工作获得的 LP 转换成对宠物的照顾。

## 工作奖励建议

| 行为 | 成长值 | LP | 说明 |
|---|---:|---:|---|
| 每日打开 | +2 | +5 | 每日轻量奖励，按自然日去重 |
| 创建任务 | +5 | +8 | 鼓励启动工作流 |
| 开始转写 | +2 | +3 | 轻量过程奖励 |
| 完成转写 | +12 | +18 | 核心工作奖励 |
| 完成 AI 总结 | +10 | +15 | 核心工作奖励 |
| 导出结果 | +6 | +10 | 闭环奖励 |
| 点击/抚摸/鼓励 | +1 | +1 | 情感互动，每类每日限制 |

一个普通用户完成一次完整工作流时，大致获得：

```text
成长值：35-45
LP：45-60
```

这是后续等级曲线和食物价格的基础假设。

## 等级上限

宠物等级上限为 `255`。

`255` 级不是为了让用户短期刷满，而是提供长期陪伴目标。用户前期应该快速升级，中期稳定推进，后期把升级变成长期沉淀。

## 等级阶段

阶段用于表达陪伴关系，不直接等同于稀有度。

| 阶段 | 等级范围 | 名称 | 情感定位 |
|---|---:|---|---|
| 1 | Lv.1-10 | 小小初遇 | 它刚来到桌面，开始认识用户 |
| 2 | Lv.11-30 | 轻轻熟悉 | 它开始熟悉用户的工作节奏 |
| 3 | Lv.31-60 | 稳定陪伴 | 它能稳定回应用户的工作状态 |
| 4 | Lv.61-100 | 一起成长 | 用户和宠物形成习惯性陪伴 |
| 5 | Lv.101-140 | 默契养成 | 宠物反馈更温柔，更贴近用户节奏 |
| 6 | Lv.141-180 | 深深羁绊 | 宠物成为长期工作陪伴的一部分 |
| 7 | Lv.181-220 | 长久相伴 | 宠物承载长期使用记忆 |
| 8 | Lv.221-255 | 不离不弃 | 最高陪伴阶段，强调纪念和沉淀 |

## 升级曲线

升级曲线采用分段递增。前期升级频繁，后期升级成本逐步上升。

| 等级段 | 每级所需成长值 | 阶段体验 |
|---|---:|---|
| Lv.1-10 | 15-30 | 新手期，快速反馈 |
| Lv.11-30 | 35-60 | 熟悉期，基本每天可升级 |
| Lv.31-60 | 70-110 | 稳定期，1-2 天一级 |
| Lv.61-100 | 120-180 | 成长期，2-3 天一级 |
| Lv.101-140 | 200-280 | 默契期，3-5 天一级 |
| Lv.141-180 | 300-400 | 深度期，4-6 天一级 |
| Lv.181-220 | 430-560 | 长期陪伴，约 1 周一级 |
| Lv.221-255 | 600-800 | 终局沉淀，长期目标 |

建议采用公式生成，而不是为 255 级手写表。

推荐公式：

```text
required_exp(level) = round(base(level) * stage_multiplier(level))
```

也可以先用分段表实现，后续再抽象为公式。

## 食物经验策略

食物提供固定成长值。

同一种食物在 Lv.1 和 Lv.200 时提供的成长值必须一致。后期食物占比变低，是因为升级所需成长值增加，而不是食物被削弱。

| 食物档位 | 价格区间 | 固定成长值 | 定位 |
|---|---:|---:|---|
| 日常小食 | 25-45 LP | +3 到 +6 | 前期常用，轻量照顾 |
| 轻量甜点 | 50-70 LP | +7 到 +10 | 日常补充 |
| 正餐/高级甜点 | 75-95 LP | +11 到 +16 | 中期主力 |
| 稀有食物 | 100-140 LP | +18 到 +24 | 阶段冲刺 |
| 纪念食物 | 160+ LP | +28 到 +36 | 后期稀有奖励 |

示例：

```text
Lv.8 升级需要 25 成长值，+12 食物很明显。
Lv.88 升级需要 160 成长值，+12 食物是有效补充。
Lv.220 升级需要 600 成长值，+12 食物主要是陪伴反馈。
```

这保证食物价值稳定，也避免用户觉得后期系统暗中削弱食物。

## LP 经济策略

LP 是工作价值货币，不是真钱货币。

普通用户一天获得约 `45-60 LP`。据此反推购买节奏：

| 消费内容 | 价格建议 | 用户节奏 |
|---|---:|---|
| 普通食物 | 25-60 LP | 每天可以买 1 个 |
| 中级食物 | 70-100 LP | 1-2 天攒 1 个 |
| 高级食物 | 110-160 LP | 2-4 天攒 1 个 |
| 普通装扮 | 120-260 LP | 3-6 天攒 1 个 |
| 场景 | 180-480 LP | 1-2 周目标 |
| 高级装扮/场景 | 500+ LP | 长期目标 |

LP 不能过度膨胀。食物可以让用户每天有消费出口，装扮和场景承担长期攒点目标。

## 每日节奏

不建议给食物成长值做递减。建议控制的是获取入口，而不是削弱已购买食物。

推荐限制：

- 互动类成长值每日上限：每类 20 次。
- 每日打开奖励按自然日去重。
- 工作流奖励按任务 ID 去重。
- 食物不限每日使用，但受 LP 获取速度和购买成本自然约束。

如果未来需要控制极端刷食物，可以限制每日购买数量或部分食物库存刷新，而不是降低食物经验值。

## 商品解锁策略

商品解锁以等级为主，里程碑为辅。

| 内容 | 解锁条件建议 |
|---|---|
| 基础食物 | Lv.1 |
| 普通食物 | Lv.5 |
| 普通装扮 | Lv.10 |
| 基础场景 | Lv.20 |
| 中级食物 | Lv.30 |
| 高级装扮 | Lv.50 |
| 高级场景 | Lv.80 |
| 稀有食物 | Lv.100 |
| 纪念徽章 | Lv.140+ 或里程碑 |
| 顶级装扮/场景 | Lv.180+ |
| 终局纪念内容 | Lv.221+ |

`levelGate` 应成为主要字段。`stageGate` 可以保留用于展示和兼容，但不要成为核心判断。

## 反馈体系

宠物反馈必须服务情感，不要像传统数值游戏。

| 事件 | 反馈 |
|---|---|
| 吃食物 | 治愈台词、吃东西动作、`+成长值` 浮动动画 |
| 升级 | 庆祝台词、短动画 |
| 阶段突破 | 更强台词、解锁提示 |
| 装扮 | 宠物回应“戴好了” |
| 场景 | 宠物回应“这里更像我们的角落” |
| 徽章 | 宠物回应“这是我们一起攒下来的证明” |
| 长期活跃 | 更深层陪伴台词 |

食物台词方向：

- 被照顾感：谢谢你记得我。
- 陪伴感：我会继续在这里陪你。
- 恢复精神：我感觉更有力气了。
- 少量数值：成长值悄悄 +N。

## UI 展示策略

宠物阶梯区域应展示：

```text
当前等级：Lv.88
当前阶段：一起成长
当前成长值：xxxxx
距离下一级：xx / xxx
下一阶段：默契养成 Lv.101
```

食物卡片展示：

```text
成长值 +12
价格 75 LP
持有 x3
```

个人仓库食物也必须展示固定成长值，避免用户不知道食用收益。

## 长期目标

到 Lv.255 后不建议让系统停止。

满级后可以进入纪念循环：

- 继续获得 LP。
- 继续购买食物、装扮、场景。
- 解锁满级纪念台词。
- 记录陪伴天数、完成任务数、总结次数等长期数据。

满级不是结束，而是“这个宠物已经成为长期伙伴”的标记。

## 落地优先级

第一阶段：

- 定义 255 级曲线。
- 替换当前线性等级算法。
- 更新宠物阶梯 UI。
- 保持食物固定成长值。

第二阶段：

- 调整商品 `levelGate`。
- 增加升级和阶段突破反馈。
- 完善食物、装扮、场景台词池。

第三阶段：

- 增加长期纪念内容。
- 增加满级后陪伴统计。
- 根据真实使用数据调参。

## 策略结论

Liberty 宠物体系应采用：

```text
255 级长期成长
+ 分段升级曲线
+ 工作行为主线成长
+ LP 经济
+ 固定食物成长值
+ 等级解锁内容
+ 情感化桌宠反馈
```

这套系统的关键不是让用户快速刷满，而是让每一次真实工作都能积累成长期陪伴关系。
